What these numbers are not

Read before quoting

These are subsets, not full leaderboard runs: 40 problems per dataset and 105 tool cases. A 95% score on 40 problems is anything from about 83–99%.

We could not run the original GLM-5.3-Flash on the same harness: it does not fit in 128 GB. That is the job of the fidelity tests below.

HumanEval and MATH are old and likely seen in training. They show the build still works, not how it ranks against frontier models.

02 · Fidelity

How close it stays to the original

48 held-out conversations (521,901 tokens) were run through full-precision GLM-5.3-Flash once, keeping its top-64 predictions at every position. Each build is scored against that. Lower KL divergence is closer; top-1 is how often both pick the same next token.

Why "assistant" tokens

Splitting by who wrote the text

On positions where the model writes its own answer, GLM 5.3 Flash-sauhard diverges by 0.108 and agrees on the top token 92.4% of the time.

On text a user or a tool wrote, KL is large (2.8 and 6.9) for every build, including near-lossless ones: neither model can predict a user's next word. It still moves with pruning, so we track it as a comprehension signal rather than a quality score.

04 · Not measured yet

Open items

Public leaderboard scores. The original GLM-5.3-Flash scores 42 on the Artificial Analysis index at medium effort, one point above Claude Sonnet 5.5. GLM 5.3 Flash-sauhard has not been run on that suite; from its fidelity we expect 40–41, but that is an estimate.

Long context at 64K to 128K. Fidelity was measured on documents up to 64K tokens. Retrieval at 128K has not been tested.

Speculative decoding. The draft head is in the weights; until it is verified, all speeds above are plain decoding.
